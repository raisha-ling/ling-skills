# Instructions for agents working in this repo

When you add, remove, or rename a skill/plugin here, always update the "What's in it" table in
`README.md` in the same change: plugin name, skill name, privilege level, and a one-line
description pulled from the skill's `SKILL.md` frontmatter/About section. Do this before opening
a PR — an out-of-date README is worse than none, since people trust it as the index of what's
available.
